### "Is my conversation data private?"

**Yes, with standard Firebase security.**

- Conversations are stored in your private Firestore collection
- Only you (and system administrators for maintenance) can access your chat history
- Firebase Authentication ensures row-level security
- No conversation data is sold or shared with third parties
- HTTPS-only communication

See the [Privacy Policy](/docs/privacy) for complete details.

### "Can I use it offline?"

**Not currently**—DMN Chat requires internet connection for:

- Gemini API calls (AI responses)
